# Italian Pizza Website

A responsive restaurant website concept built with **HTML, CSS, and JavaScript** for Italian Pizza, a local restaurant in Dera Ismail Khan.

The project focuses on creating a more convenient digital experience for customers, including browsing the menu, exploring deals, placing orders, checking order status, and managing membership features.

## Features

- Responsive restaurant website
- Online menu
- Deals and promotions
- Shopping cart
- Checkout interface
- Order status interface
- Membership system interface
- Admin interface concept
- Contact page
- Privacy Policy and Terms pages
- SEO-friendly structure
- `robots.txt`
- `sitemap.xml`
- Mobile-friendly design

## Technologies

- HTML5
- CSS3
- JavaScript

## Purpose

This project was created as a website concept and portfolio project to demonstrate how a local restaurant can improve its online customer experience through a modern website.

The project is part of my web development work at **Arlins Code**.

## Status

This is a **demo/portfolio project** and is not currently connected to a live restaurant ordering or payment system.
